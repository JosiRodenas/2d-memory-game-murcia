## 🎨🖌️🔧 Sobre el proyecto
Este juego nació como el proyecto final de la asignatura Entornos de Desarrollo (1.º de DAM).

Arte propio: Todo el diseño visual y la ilustración de las cartas se crearon desde cero, inspirados en la cultura y elementos típicos de Murcia.

Desarrollo: El código contó con la supervisión de nuestro profesor. La versión actual incluye mejoras de rendimiento y corrección de errores (como la optimización en el bloqueo de ciertas cartas).


## 🚀 A jugar!
1. Clona este repositorio.
2. Abre el proyecto en Unity Hub.
3. Ejecuta la escena principal en la carpeta `Assets/Scenes`.
